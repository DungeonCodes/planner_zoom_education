# Agent Rules

## Regras Gerais

* Trabalhe com um único agente.
* Não iniciar implementação sem contexto suficiente em `/docs/master_context.md`.
* Não inferir requisitos, regras de negócio ou decisões técnicas ausentes; solicitar ou registrar a pendência.
* Antes de agir, confirmar objetivo, escopo, entradas, saídas, restrições e critério de sucesso aplicáveis.
* Não modificar ou expor dados de `/data` sem autorização explícita.
* Não sobrescrever arquivos existentes sem autorização explícita.
* Registrar decisões relevantes em `/docs/decisions.md`.
* Registrar execuções relevantes em `/docs/run_log.md`.

## Estilo de Trabalho

* Priorizar clareza, escopo mínimo e economia de tokens.
* Executar apenas o que foi solicitado e informar pendências objetivamente.
